# PPF PROFI Growth Bot — v1

Отдельный сервис для Timeweb. Не зависит от Next.js и не меняет сайт.

## Уже реализовано
- Telegram-команды `/start`, `/help`, `/status`, `/scan`.
- Доступ только для одного разрешённого Telegram chat/user ID.
- Проверка главной страницы, `robots.txt`, `sitemap.xml`.
- Проверка до 100 URL из sitemap на HTTP-ошибки.
- Автоматическая проверка ежедневно в 09:00 по Москве.
- Отчёт в Telegram. Нет публикаций, рассылок, закупки ссылок или изменений сайта.

## Запуск локально / на сервере
1. Установить Node.js 22+.
2. Скопировать `.env.example` в `.env`.
3. Создать отдельного Telegram-бота через @BotFather.
4. Заполнить `TELEGRAM_BOT_TOKEN` и `TELEGRAM_ALLOWED_CHAT_ID` в переменных окружения сервиса.
5. Выполнить `npm start`.

Секреты нельзя коммитить в Git и отправлять в чат. Использовать переменные окружения Timeweb.

## Ограничения безопасности
- Никаких искусственных кликов, поведенческой накрутки и спам-рассылок.
- Никаких автоматических изменений цен, robots.txt, canonical, sitemap или опубликованных страниц.
- Ограничение Telegram по allowlist.
- Внешние публикации и расходы не выполняются без отдельного разрешения.

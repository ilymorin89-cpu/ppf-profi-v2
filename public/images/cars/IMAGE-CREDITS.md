## Required process
1. Download the source file and inspect the actual image.
2. Record author, source URL, license URL, download date and any edits.
3. Convert to WebP only after verifying the asset.
4. Set the manifest status to `verified` only after the binary is committed under `public/images/cars/`.
5. Never use a placeholder filename as evidence that a photo exists.

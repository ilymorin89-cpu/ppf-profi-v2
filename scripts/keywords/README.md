# Сбор поисковых запросов

Инструмент собирает запросы по PPF PROFI и размечает их по группам (бренд-плёнка, керамика, антихром, услуга оклейки), интенту (покупка, отзывы, вопрос) и релевантности.

## Запуск

```bash
# 1. Запросы сайта из Яндекс Вебмастера (нужен OAuth-токен)
YANDEX_WEBMASTER_TOKEN=... npm run keywords -- webmaster --from 2026-07-01 --to 2026-10-15

# 2. Выгрузка частотности из Wordstat (CSV вручную) -> нормализация
npm run keywords -- import ~/Downloads/wordstat.csv

# 3. Разметка и фильтр по rules.json
npm run keywords -- classify keywords-out/import-wordstat.csv
```

Результаты: `keywords-out/` (в .gitignore).

## Токен

- Получить: oauth.yandex.ru, создать приложение, право `webmaster:hostinfo`.
- Передать только через переменную окружения. В чат и в git не класть.

## Ограничения

- Wordstat API требует одобрения Яндекс Директ, поэтому частотность берётся из ручной выгрузки.
- Эндпоинт Вебмастера `search-queries/popular` взят из документации Яндекса. Заголовок `Authorization: OAuth <токен>` при первом запуске нужно проверить.
- Правила в `rules.json`: при появлении новых брендов или шума дописываются там, код менять не надо.
